# SRIRAM PRESS Website

A modern, responsive website created for SRIRAM PRESS - a quality printing services shop located in Chittur, Palakkad, Kerala, India.

## Features

- **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices
- **Interactive 3D Carousel**: Showcasing services with smooth animations
- **Product Gallery**: Display of printing products and services
- **Contact Integration**: Direct WhatsApp, Instagram, and Gmail links
- **Modern UI**: Dark theme with gradient backgrounds and smooth transitions

## Services Offered

- Photo Printing & 4K Printing
- Frames & Custom Framing
- Flyers & Brochures
- Posters & Banners
- Trophy Designing
- Polaroid Printing
- Custom Stickers

## Development Setup

### Prerequisites

- [Visual Studio Code](https://code.visualstudio.com/)
- [Node.js](https://nodejs.org/) (for development tools)
- [Python 3](https://python.org/) (for local server)

### Quick Start with VS Code

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Midhun-M-git/press-website.git
   cd press-website
   ```

2. **Open in VS Code**:
   ```bash
   code sriram-press.code-workspace
   ```
   OR
   ```bash
   code .
   ```

3. **Install recommended extensions** (VS Code will prompt you):
   - Live Server
   - Auto Rename Tag
   - CSS Peek
   - Prettier Code Formatter
   - Auto Close Tag

4. **Start development server**:
   - **Method 1**: Right-click on `press/pressnew.html` and select "Open with Live Server"
   - **Method 2**: Use VS Code command palette (`Ctrl+Shift+P`) and run "Live Server: Open"
   - **Method 3**: Run terminal command: `npm run dev`

### Available Scripts

```bash
npm run start      # Start development server
npm run dev        # Start development server
npm run format     # Format all HTML, CSS, JS files
npm run lint       # Lint JavaScript files
npm run serve      # Start live-server
npm run preview    # Preview on port 8080
```

### VS Code Features Included

- **Live Server**: Real-time preview with auto-reload
- **Debugging**: Chrome debugger integration
- **Code Formatting**: Prettier integration with format on save
- **IntelliSense**: Enhanced HTML, CSS, JavaScript support
- **Extensions**: Curated list of recommended extensions
- **Tasks**: Pre-configured build and format tasks
- **Workspace**: Multi-folder workspace setup

## Troubleshooting VS Code Issues

### Issue: "Cannot open with Live Server"
**Solution**: Install the Live Server extension or use `npm run dev`

### Issue: "No code formatting"
**Solution**: Install Prettier extension and ensure format on save is enabled

### Issue: "JavaScript errors not showing"
**Solution**: Install ESLint extension and check `.eslintrc.json` configuration

### Issue: "Auto-complete not working"
**Solution**: Ensure all recommended extensions are installed

### Issue: "Debugging not working"
**Solution**: Use F5 or Run > Start Debugging with Chrome installed
